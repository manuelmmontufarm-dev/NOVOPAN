Instalar el simulador en la computadora

La forma recomendada es instalarlo como app: queda con logo en el escritorio, se abre con un clic y funciona sin internet. Abajo también está la opción sin instalar (USB).

🖥️ Instalar como app Recomendado

Un programa de verdad: un clic para abrir, ventana propia con logo, funciona sin WiFi y se queda conectado al CSV. Solo necesita internet una vez, para instalarlo.

  1. En la PC de planta, abre novopan.vercel.app/simulador-final en Chrome o Microsoft Edge.
  2. Arriba a la derecha, en la barra de direcciones, clic en el ícono Instalar (una pantalla con una flechita ⤓). Si no aparece: menú ⋮ → Apps → Instalar este sitio como aplicación (en Edge: Aplicaciones → Instalar este sitio).
  3. Clic en Instalar. Queda en el escritorio y en el menú Inicio con el logo verde «Simulador NOVOPAN».
  4. Ábrela con un clic → botón Conectar CSV → elige el archivo del HMI. Listo: conectado y funcionando sin internet.

Después de instalarla ya no necesita internet. Al abrirla exige el CSV conectado (no muestra datos de prueba). Si la PC se reinicia, reconecta el CSV con un clic (recuerda el último archivo).

Opción B · sin instalar (o si la PC nunca tiene internet)

Baja este paquete a un USB y córrelo con doble clic. Abre en una ventanita local; no se instala. Útil si la PC no puede conectarse ni una vez a internet.

1) Primero descomprime el ZIP completo. No abras el lanzador desde dentro de WinRAR o del ZIP: clic derecho en el archivo .zip → Extraer todo, y recién entonces entra a la carpeta y abre el lanzador. (Si abres el .bat sin extraer, dirá que falta servidor.ps1.)

2) Usa el lanzador, no el .html. Abrir el .html con doble clic no funciona: el navegador bloquea los datos. El lanzador lo abre bien por ti.

Ábrelo en tu computadora

🪟 Windows

  1. Clic derecho en el ZIP descargado → Extraer todo… → Extraer. No lo abras sin extraer.
  2. Entra a la carpeta que se creó y doble clic en ABRIR SIMULADOR (Windows).bat.
  3. Se abre una ventana negra y, enseguida, el navegador con el simulador. Deja la ventana negra abierta mientras lo usas.
  4. Para cerrarlo: cierra la ventana negra.

Si te aparece WinRAR pidiendo licencia: dale Cerrar, no necesitas comprarlo. Solo úsalo (o el explorador de Windows) para extraer la carpeta.

Si Windows muestra “Windows protegió tu PC”: clic en Más información → Ejecutar de todas formas. Es seguro: es un archivo local tuyo.

🍎 Mac

  1. Doble clic en el ZIP para descomprimirlo.
  2. Doble clic en ABRIR SIMULADOR (Mac).command.
  3. Se abre la Terminal y luego el navegador con el simulador. Deja la Terminal abierta mientras lo usas.
  4. Para cerrarlo: cierra la ventana de la Terminal.

La primera vez, si dice “no se puede abrir porque es de un desarrollador no identificado”: clic derecho sobre el archivo → Abrir → Abrir.

¿No quieres descargar nada y tienes internet? El simulador también está en vivo: novopan.vercel.app/simulador-final

🌉 Puente a la nube — para ver la línea desde casa

Esto es aparte del simulador. Se instala en UNA compu de planta: la que ve el archivo CSV del HMI. Sube ese CSV a la nube cada 2 segundos para que puedas ver la Línea 1 · Sección 2 desde tu casa o el celular. Solo lee el archivo — nunca lo modifica ni toca el HMI.

🌉 Puente CSV → nube (listo para usar) Ya viene configurado: nada que editar, sin instalar dependencias. Arranca solo. Planta

🪟 Instalar (2 clics)

  1. En la compu de planta (la que ve el CSV del HMI), que tenga Node.js (nodejs.org, LTS). Si el puente ya corrió antes, ya lo tiene.
  2. Baja el ZIP de arriba y extráelo (clic derecho → Extraer todo).
  3. Doble clic en INICIAR.bat. Listo — arranca y queda corriendo solo cada vez que se prende la compu (invisible).

¿Está funcionando? Doble clic en SALUD.hta (dentro de la carpeta): se abre una ventanita 🟢/🔴 con la última subida. Si ya tenías la versión vieja corriendo, cierra su ventana negra primero.

El paquete abre el simulador en localhost:8080 con un mini-servidor incluido. Dentro del ZIP encontrarás un LEEME.txt con estos mismos pasos.
